# AI美女時計

AI が生成した女性の写真の、ホワイトボード(黒板)に、**いまの時刻**を手書き風に書いて見せる、時計のサイトです。写真は一定の間隔で、フェードしながら入れ替わります。

- 公開 URL: https://ai-bijo-clock.pages.dev/
- 画像はすべて AI 生成です。

## できること

| ページ | 内容 |
|---|---|
| `/` 時計 | 白板に現在時刻とボードの一言を表示。写真が自動で切り替わる。左下のしおりボタンで、気に入った子を「秘密の推しアルバム」に入れる |
| `/album` 秘密の推しアルバム | 入れた子が新しい順に並び、その子からの個別メッセージが読める。保存先は、そのブラウザの中だけ |
| `/ranking` みんなの推しランキング | 全員のしおりの数が多い順。同じ件数は同じ順位 |

### 時計のしくみ

- 写真ごとに、白板の四隅の座標を持ち、CSS の `matrix3d` で、白板の傾きに合わせて文字を描きます。文字は SVG フィルターで、手書き風にゆがませます。
- 写真の色から、インクの色を決めます(影なら暗く、暖色光なら暖かく)。
- 絵を切り替える間隔は、本番 15 秒です(テスト中は 6 秒)。
- 表示順は、全員を 1 周(エポック)で 1 回ずつ出す、シャッフル周回です。周の変わり目も含めて、同じ子が、全体の約 1/4 の区間以内には戻ってきません。人気(しおりの数)が多い子は、周の最後の「おかわり枠」に入りやすくなります。順番は、区間番号だけから決まるので、どの端末でも、ほぼ同じ子が、同じ時刻に出ます。
- アルバムから開いた子は、30 秒だけ固定して見せ、そのあと自動の切り替えに戻ります。

### しおりの全体集計

- しおりを入れた/外したことを、匿名のブラウザ番号(個人は特定しません)と一緒に、サーバーへ送ります。
- アルバムとサーバーの記録は、ページを開くたびに照合して、揃えます。
- 1 つのブラウザが 1 日にできる操作は、300 回までです。

## 構成

```
index.html  album.html  ranking.html  messages_check.html   画面
cards.js        各写真の座標・メッセージ(ビルドで生成)
votes.js        しおりの集計の通信
images/ thumbs/ 写真(WebP)とサムネイル
functions/api/  Cloudflare Pages Functions
    save.js     しおりの記録(POST)
    counts.js   全員分の件数と、最新の保存時刻(GET)
    mine.js     自分の匿名番号が保存している一覧(GET)
```

- ホスティング: Cloudflare Pages(GitHub の main ブランチに push すると、自動で反映)。
- データベース: Cloudflare D1(`saves` `counts` `ops` の 3 表)。
- アクセス解析: Cloudflare Web Analytics(Cookie を使わない)。
- 画像の生成・登録・ビルドの手順は、このリポジトリには含みません(公開用の成果物だけを置いています)。

## プライバシー

- 個人を特定する情報は、集めていません。しおりの記録は、ブラウザごとにランダムに作った番号だけで管理します。
- しおりの内容(自分のアルバム)は、そのブラウザの中にも保存されます。ブラウザのデータを消すと、アルバムも消えます。
